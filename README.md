# Word Sprout 英文單字 App

涵蓋多益約 500～990 分常見字彙，內含 4,334 個不重複的單字與片語、繁體中文解釋、英文例句、例句翻譯、語音朗讀、選擇題測驗與學習進度保存。字庫不依分數分級，改以實際使用情境分類。

多益主辦單位沒有公布官方的分數級距單字表，因此本 App 的內容是依多益常見職場、商務及日常溝通情境整理的完整實用字庫，並非 ETS 官方指定清單。

## 上傳 GitHub Pages

1. 將 ZIP 解壓縮。
2. 把解壓縮後的所有檔案上傳到 GitHub Repository 的根目錄。
3. 到 **Settings → Pages → Build and deployment**。
4. Source 選 **Deploy from a branch**，Branch 選 **main**，Folder 選 **/ (root)**，再按 **Save**。

## 安裝到手機主畫面

- iPhone：用 Safari 開啟網站，按「分享」→「加入主畫面」。
- Android：用 Chrome 開啟網站，按畫面上的「安裝 App」，或從瀏覽器選單選擇安裝。

學習進度會保存在目前的瀏覽器與裝置中。清除瀏覽器網站資料時，進度也會一併清除。

第一次連線開啟完成後，主要學習內容可在沒有網路時繼續使用；朗讀音色則由手機或電腦內建的英文語音提供。
